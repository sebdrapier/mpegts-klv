# Security Policy

## Supported versions

Only the latest major version (0.x) receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately via
[GitHub Security Advisories](https://github.com/sebdrapier/mpegts-klv/security/advisories/new).
You should get a response within 7 days. Malformed input that makes the parser throw,
hang or read out of bounds is in scope.
